# food-picture-01 — The Double Smash Cheese Pull

A make.fun food-picture-01 entry: a wood-fired double smash burger with molten cheddar dripping over two patties, golden brioche, steam rising, on a dark walnut board. 1024x1024 PNG in `entry.png`.

## Run

`node main.ts` — copies `entry.png` to `$MAKEFUN_OUTPUT_DIR` (default `/output`). Node 22, standard library only.
